Document Overview

This document serves as an exhaustive technical module breakdown and feature specification of the DHAcquisitions.co platform. It outlines the core architecture layers, functional modules, payment lockers, identity verification paths, administrative portals, and the underlying DevOps configuration required to build, test, and deploy the system.

1. Identity & Access Control Module (IAM)

This module manages user registration, security credentials, session authorizations, and routing boundaries across multiple user categories.

  • Multi-Role Architecture: Segregates user permissions into distinct levels: Guest (unauthenticated), Registered User (buyer/seller), Recruiter (employer), and Administrator.
  • Cryptographic Password Hashing: All password entries are encrypted using the BCrypt hashing function on the Spring Boot backend prior to persistence.
  • Stateless Session Verification: Authenticated user requests are validated via JSON Web Tokens (JWT) transmitted securely via HTTP headers.
  • Authentication Guards: Implements a global client-side router interceptor (ProtectedRoute) that monitors verification status. Unauthorized requests to dashboard views or listing creator paths are blocked and redirected to the login endpoint.

2. Acquisitions & Listings Marketplace Module

This module drives the listing, indexing, filtering, and detailing of major healthcare property assets.

  • Listing Classification: Allows sellers to registry opportunities under five core healthcare categories: Hospitals, Diagnostic Centres, Pharma Companies, Dental Clinics, and Pharmacies.
  • Geographical Filtering: Integrates dynamic lookup services fetching verified city and state lists from the backend master data tables, replacing static frontend elements.
  • Query Processing: Multi-variable search engine supporting keyword lookups, category selection, price brackets, and region bounds.
  • Fractional Investments (Partial Stakes): Dedicated sub-portal managing fractional share sales, featuring a deduplication engine ensuring listings are not double-counted across database search runs.

3. Careers & Talent Portal Module

A specialized sub-marketplace allowing medical facilities to post professional vacancies and candidates to apply.

  • Job Registry: Recruiters post details including category, salary bounds (LPA), experience prerequisites, open vacancies, and application deadlines.
  • Application Pipeline: Secure upload mechanism for candidate CVs (PDF files) with custom styled choose-file inputs, completely bypassing native browser defaults.
  • Recruiter Privacy Shield: Masks contact email addresses of recruiters (e.g., converting to m********@domain.com) for unauthenticated visitors. Only signed-in users can view full contact information.

4. Payment Security & Data Locking Module

Secures business broker information behind verified payment gates.

  • Data Access Restrictions: Restricts sensitive seller/broker details (FullName, email, and phone number) behind a cryptographic lock.
  • Razorpay Integration: Connects with the Razorpay API to collect a secure fee of ₹1,000 to unlock details.
  • Locker Sync: Listens for transaction verify callbacks. Upon approval, updates database logs to permanently link the user identity to the unlocked listing.

5. Governance & Admin Auditing Module

Provides administrators with full overview and verification controls over platform activities.

  • Lifecycle Governance: Review, approve, reject, or delete marketplace listings and job vacancy entries.
  • Identity Verification (KYC): Review uploaded identity documents and approve or reject user verification requests.
  • Bulk Account Operations: Interface to handle database cleanup, including cascading user deletion that handles foreign keys (inquiries, listings, applications).
  • Security Audit Logging: Records client activity (login events, payment transactions, identity verifications), logging actor IDs, timestamps, event details, and IP addresses.

6. System Technology Stack & Infrastructure

Defines the systems, deployment, and deployment orchestration architecture of the platform.

6.1 Frontend Layer

  • React.js (Single Page Application architecture).
  • Tailwind CSS (utility-first UI design) and Vanilla CSS overrides for Glassmorphism.
  • React Router DOM (client-side routing and protected boundaries).

6.2 Backend Layer

  • Spring Boot (Java RESTful Web Service architecture).
  • Spring Security (authenticating JWT requests, role mapping).
  • Hibernate / Spring Data JPA (database relational mapping).

6.3 Persistence Layer

  • MySQL relational database engine.
  • Database schema maintaining Users, Listings, Jobs, Payments, and Logs.

6.4 Infrastructure & Delivery Pipeline

  • Docker (isolated containers for DB, backend service, and frontend client).
  • Nginx (acting as a reverse-proxy router handling SSL encryption).
  • GitHub Actions (.yml script configurations automating build and server-pull actions).
